# BEEntO
this is a cute web game, to click food that looks like pusheen in a bento box and hear the meows from them!
**Play demo**
*https://github.com/ALEXXXnh/BEEntO*

## what does the page have?
* a start page
* a clicker that sounds and looks like cats
* a recipe for your bento box

## how was it created?
1. html (web, images, sounds)
2. css (web design, function of scenes display)
3. javascript (change of scenes, cursor, audio&music)
